# recsys-rl-finetuning

RL-дообучение последовательной рекомендательной модели (GPT-2) на KION (МТС).
Задача T-Lab №2. Всё исследование в одном ноутбуке: [solution.ipynb](solution.ipynb).

> Статус: каркас. Результаты и выводы будут добавлены после прогонов на Kaggle.

## Постановка

1. Базовая модель: GPT-2, токены = `item_id`, задача next item prediction.
2. Reward model: предсказывает `watched_pct` по истории и объекту-кандидату.
3. RL (REINFORCE/GRPO + KL к базовой модели): сдвиг генерации к высокому ожидаемому reward.
4. Анализ: reward vs релевантность (Recall/NDCG/MAP@K), разнообразие, reward hacking,
   генерация на 5 шагов вперёд, варианты функции вознаграждения.

## Протокол оценки

- Разбиение строго по времени (глобальные даты), без утечек.
- Одинаковый протокол для базовой и RL-модели.
- Доверительные интервалы: бутстреп по пользователям.

## Воспроизведение (Kaggle)

1. Загрузить `interactions.csv`, `items.csv`, `users.csv` как Kaggle Dataset (приватный).
2. Создать ноутбук, загрузить `solution.ipynb`, подключить датасет, включить GPU (T4/P100).
3. Запустить ячейки по порядку. Флаг `SMOKE = True` в первой ячейке даёт быстрый прогон на малой выборке.
4. Тяжёлые шаги кэшируются в `cache/` и `checkpoints/` (не коммитятся); лёгкие метрики и логи лежат в `results/`.
